# GradeGoal – Academic Grade Target Simulator

## Deskripsi

GradeGoal merupakan aplikasi console berbasis TypeScript yang dirancang untuk membantu mahasiswa mengelola komponen penilaian mata kuliah, menghitung kontribusi nilai, serta memperkirakan nilai yang dibutuhkan untuk mencapai target nilai akhir.

Project ini dikembangkan dari project UTS GradeGoal dengan penambahan fitur pengelolaan data dan penerapan materi Pemrograman Dasar.

## Tujuan

- Mengelola komponen penilaian mata kuliah.
- Menghitung kontribusi nilai.
- Simulasi pencapaian target nilai akhir.
- Menerapkan konsep pemrograman TypeScript.
